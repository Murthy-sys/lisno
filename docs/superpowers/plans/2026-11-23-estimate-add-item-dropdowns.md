# Sales estimate Add items dropdowns

Implement the [approved specification](../specs/2026-11-23-estimate-add-item-dropdowns-design.md).

1. **Baseline and ownership.** The integration owner captures current diffs and inspects the Sales builder, shared EstimateItemPicker, ClientQuotation caller and picker tests. The shared picker also serves Client Quotation. Scope the three-dropdown interaction to Sales.
2. **Implement the Sales picker.** The frontend owner handles production components and any scoped styles. Feed the picker the complete room-eligible target list so all choices are reachable. Derive Main Basket, Sub Basket and Main Line options by stable identity, including a Direct items choice for null Sub Basket IDs. Clear dependent selections when a parent changes and invalidate stale choices on room or catalogue refresh. Use labeled controls and one Add button. Handle empty, unavailable and already-included choices and retain keyboard focus handling.
3. **Integrate normal estimate rows.** The same owner wires confirmation to the existing builder add handler. Verify that successful addition reveals the correct group and included row, including when the room starts empty. Retain the workspace’s edit, price, quantity and draft-save path and its permission, freshness and duplicate guards.
4. **Cover the workflow.** The regression owner updates the Sales builder and workspace tests that use the old picker. Cover dependent resets, similarly named targets, direct items, room restrictions, catalogue refresh, disabled states and duplicate prevention. Exercise adding a Balcony / Utility line, editing its quantity, saving and reopening the draft. The test slice can proceed alongside steps 2 and 3 after the baseline because it owns test files only.
5. **Verify the integrated result.** Run the focused picker, builder, workspace and affected Client Quotation tests, frontend typecheck and production build, then inspect the diff and run `git diff --check`. Exercise the three labeled dropdowns and confirmation in a browser at desktop and mobile widths, including keyboard selection and the appearance of the editable row.
