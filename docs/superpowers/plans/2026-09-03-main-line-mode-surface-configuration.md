## Fixed implementation contract

- The visible panel is **Main Line → Mode → Surfaces**, after Budgeting and before Quantity & margin.
- Overview remains free of Surface UI.
- Each reusable Surface is one dropdown option. **Examples / components** is one optional freeform description string, not child records.
- Surface masters gain ordered `typicalUomIds: string[]`; new records require at least one active UOM.
- Typical units are advisory and never drive financial calculation, conversion, Budgeting UOM, quantity slab, rate, tax, or estimated cost.
- Main Line assignment continues to persist stable IDs in `overview.surfaceIds`; this workflow never reads from or writes to `scope.surfaceIds`.
- Surface technical code is generated by the server when omitted; compatible older clients may still provide it.
- No seed, backfill, bootstrap-manifest change, production migration, new permission, new backend section, new Surface entity, or Estimator/Sales consumer is in scope.

### Task 7 integrity review - findings and disposition

**F-1 (fixed) Activation rejected retained inactive Surfaces without saying which.**
This change relaxed the save-time active-Surface check to activation only (`!context`), so a
Main Line saves cleanly and later fails activation with a bare
`409 KNOWLEDGE_REFERENCE_INVALID - "An active surface reference is unavailable."` - no name, no
field path. Decision taken by the owner: keep blocking, add attribution. Activation now names
each stale Surface and returns `payload.surfaceIds` guidance. What is allowed did not change.

**F-2 (fixed) Hidden legacy `scope.surfaceIds` shared that gate.**
Scope has no visible editor and this workflow never writes it, so a hidden inactive ID could
block activation undiagnosably. Decision taken: keep checking, attribute separately - such
references now return a distinct `scope.surfaceIds` message naming the Surface.

Both are covered by new cases in `ai-estimator-knowledge-item.service.test.ts`, including proof
that a Surface deleted outright is described ("a Surface that no longer exists") and never
